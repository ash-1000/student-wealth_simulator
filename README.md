# 💰 Student Wealth Simulator

An interactive financial simulation tool designed to help users understand how investments grow over time, build customizable portfolios, and evaluate risk using real market data.

---

## 🚀 Features

### 📊 Portfolio Builder
- Select from real stocks and indices (no random inputs)
- Allocate percentage weights dynamically
- Enforces total allocation = 100%

### 📈 Wealth Growth Simulation
- Visualizes how monthly investments grow over time
- Adjust based on age, duration, and contribution
- Demonstrates the power of compounding

### 🧠 Smart Risk Insights
- Differentiates between:
  - 📊 Index funds (more stable & predictable)
  - ⚠️ Individual stocks (higher risk & volatility)
- Provides intelligent, realistic investment guidance

### 🥧 Portfolio Visualization
- Pie chart representation of asset allocation
- Clear breakdown of diversification

### 📉 Stock Explorer
- View real stock performance (1-year data)
- Uses live financial data via Yahoo Finance

---

## ⚙️ Tech Stack

- **Python**
- **Streamlit** (UI & frontend)
- **yFinance** (real-time stock data)
- **Matplotlib** (visualization)

---

## 🧩 How It Works

1. Enter your:
   - Age
   - Monthly investment
   - Investment duration

2. Select assets from a predefined list:
   - US stocks (AAPL, TSLA, etc.)
   - Indian stocks (RELIANCE.NS, TCS.NS)
   - Indices (S&P 500, NIFTY 50)

3. Allocate percentages (must total 100%)

4. Analyze:
   - Wealth growth over time
   - Portfolio distribution
   - Risk insights

5. Explore real stock performance

---

## 📌 Key Insight

This tool highlights an important financial reality:

> Not all investments are predictable.

- Index funds tend to offer **stable long-term returns**
- Individual stocks can be **highly volatile and uncertain**

The simulator is designed to educate users—not to predict exact returns.
